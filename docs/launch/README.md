# Launch Kit

Materials for announcing the project. Replace placeholders (`<demo-link>` and any measured results) before posting. Do not add claims you have not measured.

## Before launching

- [ ] Record a 30 to 60 second screen capture: give an assistant a buggy prompt, show the unverified-claim failure, then show this skill's ranked hypotheses and `UNVERIFIED` status. Save as `assets/demo.gif` and add it to the top of the README.
- [ ] Run the six evals in `.skills/evidence-first-debugger/evals/evals.json` with and without the skill. Record real pass rates in the README. Do not publish numbers you did not measure.
- [ ] Set the GitHub repository description, topics, and social preview image (see `github-setup.md`).
- [ ] Tag a release (`v0.3.0`) and attach `evidence-first-debugger.skill`.
- [ ] Test the install script on a clean machine.

## Files

- `github-setup.md`: repository description, topics, and settings
- `show-hn.md`: Hacker News post
- `social-posts.md`: X, LinkedIn, and Reddit drafts
- `devto-outline.md`: long-form article outline
