# Security Policy

This repository contains markdown instructions and small helper scripts. It does not run a service or process user data.

## Reporting a vulnerability

If you find a security issue (for example, a script that could execute unintended commands), please report it privately using GitHub's "Report a vulnerability" option under the Security tab. Do not open a public issue for security problems.

## Scope

- `install.sh` and files under `scripts/`
- GitHub Actions workflows under `.github/workflows/`

Instruction content that causes poor assistant behavior is not a security issue; please file a skill gap report instead.
